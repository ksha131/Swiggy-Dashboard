# Swiggy Data Analysis & Dashboard

## Project Overview

This project analyzes Swiggy order data using **Microsoft Excel**.
The data was analyzed using **Pivot Tables, Pivot Charts, Filters, Slicers, and Dashboard visualizations** to identify useful business insights.

## Dataset Summary

* **Total Records:** 8,000 orders
* **Total Order Value:** ₹76.28 Lakhs
* **Net Revenue:** ₹72.99 Lakhs
* **Average Order Value:** ₹953
* **Average Delivery Time:** 40.22 minutes
* **Average Rating:** 3.85 / 5

## Key Insights

* **Delhi** recorded the highest number of orders.
* **Bakery** was the most ordered cuisine.
* **Veg** orders were slightly higher than Non-Veg orders.
* **Wallet** was the most commonly used payment method.
* The **35–44 age group** had the highest number of customers.
* Average delivery time was around **40 minutes**.
* A significant number of orders were classified as **slow deliveries**.
* Delivered orders were higher than cancelled and returned orders.
